# Carpeta de datos

Aquí debe quedar el archivo `creditcard.csv`, pero no está incluido en el
repositorio porque pesa cerca de 150 MB y GitHub no permite archivos tan
grandes.

## Cómo conseguirlo

1. Entrar a https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
2. Iniciar sesión en Kaggle
3. Darle click a "Download"
4. Descomprimir el archivo (si llega como .zip)
5. Copiar `creditcard.csv` dentro de esta carpeta (`data/`)

Al final debe quedar así:

```
data/
└── creditcard.csv
```
